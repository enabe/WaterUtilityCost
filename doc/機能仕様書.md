## 1. 概要

### 1.1 目的

ビル管理業務において、水道・電気・ガスの請求データ、子メーター検針データ、取引先・部屋・メーターマスタを一元管理し、部屋別の請求明細を自動算出して請求書を出力する。

### 1.2 対象ユーザー

- ビル管理担当者（社内利用者）
- 単一ユーザーによるデスクトップ操作を前提とする（ユーザー認証・権限管理機能はなし）

### 1.3 システム構成

| 区分 | 内容 |
|---|---|
| 種別 | Windows デスクトップアプリケーション |
| 開発言語 | C#（.NET Framework 4.8） |
| UI | Windows Forms |
| データベース | SQL Server（LocalDB / Express） |
| 起動画面 | メニュー画面（`MenuForm`） |
| 帳票 | Excel テンプレート（COM 経由で印刷） |

### 1.4 業務フロー（月次）

```mermaid
flowchart LR
    A[マスタ登録] --> B[子メーター検針登録]
    B --> C[請求データ登録]
    C --> D[請求明細データ作成]
    D --> E[請求明細確認・修正]
    E --> F[請求書印刷]
```

1. ビル・部屋・取引先・親メーター・子メーター・部屋別子メーターを登録する
2. 電気・ガス・水道の子メーター検針データを登録する（手入力または CSV 取込）
3. 水道・電気・ガスの請求データ（親メーター請求）を登録する
4. 請求明細データ作成で対象年月の明細を自動生成する
5. 水道光熱費請求明細一覧で内容を確認・修正する
6. 請求書印刷で請求書・請求一覧を出力する

## 3. 共通仕様

### 3.1 一覧画面の共通操作

| 操作 | 仕様 |
|---|---|
| 新規登録 | 空の登録画面をモーダル表示。保存後に一覧を更新 |
| 編集 | 選択行を登録画面に渡して編集。未選択時は警告 |
| 削除 | 確認ダイアログ後に削除。未選択時は警告 |
| 更新 | データベースから再読込 |
| ダブルクリック | 多くの一覧画面で編集画面を開く |

### 3.2 登録画面の共通操作

| 操作 | 仕様 |
|---|---|
| 保存 | 入力検証後、データベースへ反映して画面を閉じる |
| キャンセル | 変更を破棄して画面を閉じる |

### 3.3 起動時処理

1. データベース接続テスト
2. 接続失敗時はエラーメッセージを表示して終了
3. 接続成功時はテーブル作成・マイグレーションを実行
4. メニュー画面を表示

### 3.4 日付・年月の形式

| 項目 | 形式 |
|---|---|
| 請求年月（BillingYearMonth） | `YYYY-MM` |
| 画面の年月選択 | DateTimePicker（月初日） |
| CSV 出力の日付 | `yyyy-MM-dd` |

| 項目 | 必須 | 説明 |

- コピーして追加（既存行を複製して新規登録）
- 比較表 CSV 出力（対象年月を指定し、前月・前年との比較表を出力）

### 5.2 電気子メーター検針（F-09）

**CSV 取込**:
- 電気電灯 CSV 読込
- 低電圧 CSV 読込

ファイル選択ダイアログで CSV を選択し、取込後に一覧へ反映する。キャンセル時は変更なし。

### 5.3 ガス子メーター検針（F-10）

**CSV 取込**: ガス CSV 読込

### 5.4 水道子メーター検針（F-11）

**CSV 取込**: 水道 CSV 読込

### 5.5 検針値の利用方法

請求明細作成時、部屋別使用量は原則として **当月検針値 − 前月検針値** として算出する。ビル・種別により参照月が異なる特例あり（6章参照）。

## 7. 請求明細データ作成機能（F-15）

### 7.1 概要

**画面**: 請求明細データ作成（SCR-900）

**入力**: 受領請求年月

**操作**: 電気明細作成 / ガス明細作成 / 水道明細作成（個別実行）

**出力**: `InvoiceDetails` テーブルへの明細レコード追加

**前提条件**:
- 対象年月の請求データが登録済みであること
- 子メーター検針データが登録済みであること
- マスタ（ビル・部屋・取引先・メーター紐付け）が整合していること

**共通ルール**:
- 税込金額が 0 円の明細は登録しない
- 明細の `BillingYearMonth` には画面で指定した受領請求年月を設定する
- 請求予定日は取引先の振込方法（自動振込 / 口座振込）に応じて算出する

### 7.2 電気明細作成ロジック

**対象データ**: 指定請求年月の電気請求データ

**通常ビル（服部ビル以外）の算出フロー**:

1. 請求データの建物名に一致する請求先取引先を明細対象とする
2. 子メーター検針から部屋別使用量を算出（当月 − 前月）
3. 同一建物の部屋面積合計を専有面積合計とする
4. 部屋別共有割合 = 部屋面積 ÷ 専有面積合計
5. 部屋別基本料金 = 基本料金 × 部屋別共有割合
6. 子メーター使用量合計 = 全子メーター検針差分の合計
7. 共有部分使用量 = (親メーター使用量 − 子メーター使用量合計) × 部屋別共有割合
8. 部屋別使用量計 = 部屋別使用量 + 共有部分使用量
9. 部屋別従量単価 = 使用料金 ÷ 部屋別使用量合計
10. 部屋別従量金額 = 部屋別従量単価 × 部屋別使用量計
11. 部屋別電気料金 = 部屋別基本料金 + 部屋別従量金額

**出力明細**（部屋・請求先ごとに最大 2 行）:
- 種別: 電気、内容: `電気料金（基本料）`
- 種別: 電気、内容: `電気料金（従量電気料）`
- 単位: kWh

**服部ビルの特例**:
- 面積按分・共有部分按分は行わない
- 部屋別基本料金 = 部屋別使用量 × (親基本料金 ÷ 親使用量)
- 部屋別従量金額 = 部屋別使用量 × (親使用料金 ÷ 親使用量)
- 親使用量が 0 の場合は両方 0

### 7.3 ガス明細作成ロジック

**対象データ**: 指定請求年月のガス請求データ（親メーター単位で重複排除）

**算出フロー**:

1. 親メーターに紐づく建物の請求先取引先を明細対象とする
2. ガス種別かつ親メーター一致の子メーターを対象とする
3. 部屋別使用量 = 当月検針値 − 前月検針値
4. 同一子メーター共有部屋の面積合計を専有面積合計とする
5. 部屋別専有割合 = 部屋面積 ÷ 専有面積合計
6. 部屋別基本料金 = 基本料金 × 部屋別専有割合
7. 部屋別使用量計 = 部屋別使用量 × 部屋別専有割合
8. 部屋別単価 = 使用料金 ÷ 部屋別使用量（0 の場合は 0）
9. 部屋別従量金額 = 部屋別単価 × 部屋別使用量計
10. 部屋別ガス料金 = 部屋別基本料金 + 部屋別従量金額

**出力明細**:
- 種別: ガス、内容: `ガス料金`
- 単位: m³

### 7.4 水道明細作成ロジック

**対象データ**: 指定請求年月の水道請求データ

**通常ビル・服部ビル以外の算出フロー**:

1. 親メーター×請求年月で重複排除
2. 親メーターに紐づく子メーターがある部屋の請求先のみ対象（ParentMeterId 未設定時はビル内全請求先）
3. 水道子メーターの検針差分から部屋別使用量を算出（通常: 画面月と 2 か月前）
4. 同一子メーター共有部屋の面積合計を専有面積合計とする
5. 部屋別専有割合 = 部屋面積 ÷ 専有面積合計
6. 部屋別使用量計 = 部屋別使用量 × 部屋別専有割合
7. 部屋別単価 = 使用料金 ÷ 部屋別使用量合計
8. 部屋別従量金額 = 部屋別単価 × 部屋別使用量計
9. 部屋別基本料金 = 基本料金 × 部屋別専有割合
10. 部屋別水道料金 = 部屋別基本料金 + 部屋別従量金額

**出力明細**:
- 種別: 水道、内容: `水道料金`
- 単位: m³

**岩本ビル・ビラ・プェルタの特例**:
- 親請求データ: 画面月の**前月**を参照
- 子メーター検針: 終了 = 画面月の前月、開始 = 画面月の 3 か月前
- 請求予定日・明細の BillingYearMonth は画面月のまま

**服部ビルの特例**:
- 貸主・借主への按分ロジックを適用（専用処理）
- 借主・貸主それぞれに明細を生成

**プラザセレス石川Ⅰ 3-7F 水道の特例**:
- 部屋別使用量 = 按分前の部屋ごとの検針差分
- 単価 = (基本料金 + 従量料金) ÷ 親請求使用量
- 請求金額 = 部屋別使用量 × 単価（基本料の面積按分なし）
- 差額割当は行わない

## 9. 請求書印刷機能（F-18）

### 9.1 概要

**画面**: 請求書印刷（SCR-910）

**入力**:
- 請求年月
- 請求先（全てまたは特定取引先）

**操作**:
- 請求書印刷
- 請求一覧印刷

### 9.2 請求書印刷

**テンプレート**: `Excel/請求書.xlsx`

**処理**:
1. 指定請求年月の請求明細を取得
2. 請求先ごとに Excel テンプレートへデータ差し込み
3. 明細行の自動挿入・改ページ処理
4. Windows 印刷ダイアログを表示して印刷

**差し込み項目（例）**:
- 請求先名
- 業者名・インボイス番号
- 明細（部屋、内容、使用量、単位、金額、税率）
- 口座振込案内（口座振込フラグ ON の場合）

### 9.3 請求一覧印刷

**テンプレート**: `Excel/請求一覧.xlsx`

**処理**:
1. 指定請求年月の明細を取得
2. ブロック単位（29 行）でレイアウトし、1 ブロックあたり最大 20 件の明細を配置
3. 印刷ダイアログを表示

### 9.4 エラー条件

- テンプレートファイルが存在しない
- 対象年月の請求明細が存在しない
- Excel（COM）が利用できない

## 16. 用語定義

| 用語 | 定義 |
|---|---|
| 受領請求年月 | 光熱費会社から請求書を受領した年月。明細の `BillingYearMonth` に格納 |
| 親メーター | 供給事業者の請求単位となるメーター |
| 子メーター | テナント部屋等に設置された個別メーター |
| 請求先 | 請求書の送付先となる取引先（`IsBillingTo = true`） |
| 専有面積合計 | 按分計算の分母となる面積の合計 |
| 共有部分 | 親メーター使用量のうち子メーター合計に含まれない部分 |
