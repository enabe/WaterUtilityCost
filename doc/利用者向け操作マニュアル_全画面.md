# 水道光熱費アプリ 利用者向け操作マニュアル（全画面）

対象: メニューから開ける一覧・管理画面および、その編集（登録）ダイアログまで。  
既定の起動は `メニュー画面` です（`Program.cs` で `MenuForm` を起動）。

---

## 記号と共通ルール

### 一覧・管理画面で共通すること（該当するすべての画面）

多くの一覧画面には次のボタンがあります（文言は画面により追加があります）。

- **新規登録**: 空の状態で登録画面を開く  
- **編集**: 一覧で行を選んで登録画面を開く  
- **削除**: 選択行を削除（確認ダイアログあり）  
- **更新**: 一覧データを再読み込み  

行を**ダブルクリック**すると編集画面が開く画面もあります。

### 登録（編集）画面で共通すること

- **保存**: 入力内容を確定してデータベースへ反映する  
- **キャンセル**: 変更を破棄して閉じる

## 付録 B: 請求・検針の典型的な月次フロー（利用者向け）

1. **検針**（電気・ガス・水道の各 **子メーター検針データ管理**）で検針値を登録する  
2. 必要に応じて **請求データ管理**（水道・電気・ガス）で請求単価・条件を確認する  
3. **請求明細データ作成**で対象年月の明細を生成する  
4. **水道光熱費請求明細一覧**で内容を確認・修正する  
5. **請求書印刷**で請求書・一覧を印刷する

## 付録 C: 各機能の詳細（利用者向け）

本章は「ボタンを押した後に何が起きるか」を中心に、実運用で必要な粒度でまとめています。

### C-1. マスタ管理機能（ビル / 部屋 / 取引先 / メーター）

対象画面:

- `SCR-100/101` ビル管理・ビル情報登録
- `SCR-200/201` 部屋管理・部屋情報登録
- `SCR-300/301` 取引先管理・取引先情報登録
- `SCR-810/811` 親メーター管理・メーター情報登録
- `SCR-820/821` 子メーター管理・子メーター情報登録
- `SCR-830/831` 部屋別子メーター管理・部屋別子メーター情報登録

機能詳細:

- **新規登録**: 空フォームを開き、保存すると一覧に即反映されます。
- **編集**: 一覧の選択行を編集し、保存後に同じ一覧へ戻ります。
- **ダブルクリック編集**: 多くの管理画面で行ダブルクリックでも編集を開けます。
- **削除**: 選択行がない場合は警告表示、選択済みなら確認後に削除します。
- **更新**: データベース再読込を行い、他画面での変更を反映します。

運用上の注意:

- 明細作成前に、建物・部屋・取引先・メーターの紐付けを確定してください。
- マスタ不整合があると、検針/請求明細作成時に対象漏れや金額不整合の原因になります。

### C-2. 子メーター検針データ管理（電気 / ガス / 水道）

対象画面:

- `SCR-700/701` 電気子メーター検針データ管理・登録
- `SCR-710/711` ガス子メーター検針データ管理・登録
- `SCR-720/721` 水道子メーター検針データ管理・登録

共通機能:

- **新規登録 / 編集 / コピーして追加 / 削除 / 更新**
- コピーして追加は、既存行の内容をベースに新規レコードを作る用途です。

CSV取込:

- 電気: `電気電灯CSV読込` と `低電圧CSV読込`
- ガス: `ガスCSV読込`
- 水道: `水道CSV読込`

取込時の挙動:

- まずファイル選択ダイアログが開きます。
- キャンセルした場合は何も変更しません。
- 正常取込後は一覧に反映されるため、対象年月・建物・メーターで結果確認してください。

### C-3. 請求データ管理（水道 / 電気 / ガス）

対象画面:

- `SCR-600/601` 水道料金請求データ管理・登録
- `SCR-610/611` 電気料金請求データ管理・登録
- `SCR-620/621` ガス料金請求データ管理・登録

機能詳細:

- 子メーター検針と別に、請求計算に使う請求データを維持します。
- 一覧画面から新規・編集・削除・更新が可能です。
- ここで管理する請求データは、`SCR-900 請求明細データ作成` の入力元になります。

### C-4. 請求明細データ作成（SCR-900）

画面項目:

- `受領請求年月`（月選択）
- `電気明細作成` / `ガス明細作成` / `水道明細作成`

実行内容（要点）:

- 指定年月を対象に請求明細を自動作成します。
- 作成ロジックでは、請求データ・取引先・部屋・子メーター検針データなどを組み合わせて明細を算出します。
- 建物や月により分岐するロジック（按分や差額調整）があります。

完了・失敗時:

- 正常時は「○○の請求明細データ作成が完了しました」を表示します。
- 失敗時は詳細メッセージとログ情報が表示されるため、画面表示をそのまま記録してください。

### C-5. 水道光熱費請求明細一覧（SCR-400）

検索・絞込:

- `請求先`（部分一致）
- `建物名`（部分一致）
- `種別`（空=すべて / 電気 / 水道 / ガス）
- `検索` / `クリア`

一覧操作:

- **新規登録 / 編集 / ダブルクリック編集 / コピーして追加 / 削除 / 更新**
- 削除は対象未選択時に警告、選択時は確認ダイアログ後に実行されます。

集計表示:

- `税込金額合計`
- `使用量合計`
- `子使用量合計`
- `面積合計`

CSV出力:

- `CSV出力`
- `前月比較CSV出力`
- `前年比較CSV出力`

出力時の流れ:

- 保存先選択後にCSVを書き出し、完了メッセージを表示します。
- 出力失敗時はエラー内容を表示します。

### C-6. 請求明細登録（SCR-401）

用途:

- 明細の直接修正（請求先、建物、種別、使用量、税率、期間など）

主な入力カテゴリ:

- 基本情報: 請求先、貸主、借主、建物、部屋
- 計算関連: 使用量、子使用量、単位、税込金額、税率
- 期間関連: 親/子メータの使用開始日・終了日、請求予定日

注意:

- ここで修正した内容は請求書印刷の元データになるため、保存前に桁・単位・日付を確認してください。

### C-7. その他請求明細一覧 / 登録（SCR-500/501）

用途:

- 水道光熱費以外の請求項目を管理します。
- 操作体系は請求明細一覧と同様で、一覧から新規・編集・削除・更新を行います。

### C-8. 請求書印刷（SCR-910）

画面項目:

- `請求年月`
- `請求書印刷`
- `請求一覧印刷`

テンプレートファイル:

- 請求書印刷: `Excel/請求書.xlsx`
- 請求一覧印刷: `Excel/請求一覧.xlsx`

処理詳細:

- 指定年月の明細を取得し、Excelテンプレートへ差し込み後に印刷します。
- 印刷時はWindowsの印刷ダイアログが表示され、プリンタ選択後に印刷実行されます。

よくある停止要因:

- テンプレートファイルが見つからない
- 対象年月の請求明細が存在しない
- Excelがインストールされていない / COM起動不可

### C-9. 初期データ登録（SCR-920）

用途:

- CSVファイルからマスタを一括投入します。

対象ボタン:

- ビル情報データ登録
- 部屋情報データ登録
- 賃借人情報データ登録
- 業者情報データ登録
- 親メーター情報データ登録
- 子メーター情報データ登録
- 部屋別子メーター管理データ登録

実行時の流れ:

- ボタン押下 → CSV選択 → 読込/検証 → DB反映 → 件数メッセージ表示

注意:

- CSV列構成が想定と異なる場合はエラーになります。
- 一括登録系のため、運用データ反映前にバックアップ取得を推奨します。

### C-10. 終了操作

- メニュー画面の `終了` は確認ダイアログを表示し、`はい` でアプリを終了します。
- 作業途中の画面がある場合は、保存漏れがないことを確認してから終了してください。
